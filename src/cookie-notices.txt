! Bowser built-in cookie-notice list. Bundled with the program; Bowser never downloads it or
! updates it by itself. Each line hides one cookie-consent banner or its page-darkening overlay.
!
! Syntax (a subset of the EasyList Cookie List's element-hiding rules):
!   ##selector              hide the element on every page
!   a.com,b.org##selector   hide it on those sites (and their subdomains) only
!   ##@scroll:selector      give the element back its scrolling when a banner left it locked
! A selector may use tag names, .classes, #ids, [attribute] tests (=, ^=, $=, *=, ~=, |=),
! descendant spaces, > and + combinators and commas. Nothing else is accepted, so a rule can
! only hide or unlock what it names. A hiding rule never ends in html, body or *, so a page
! cannot be blanked; only the scroll rules name html and body, and they only restore scrolling.
!
