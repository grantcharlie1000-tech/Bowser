Questions, answered

Is ad blocking on when I install it?

Yes. Ads and trackers are blocked from the first launch. There is nothing to install or set up.

Can I turn blocking off for one site?

Yes. The Privacy panel has a blocker switch for the site you are on. Every other site stays blocked, and private tabs always block.

Can I use my own filter list?

Yes. Put a filters.txt in your Bowser profile and it becomes your list. Bowser does not fetch filter lists by itself.

Which Chrome extensions work?

Install them from the Chrome Web Store or Edge Add-ons, from a .crx file, or from an unpacked folder. WebView2 runs only part of Chrome’s extension system, so a few extensions won’t work. Extensions don’t run in private tabs.

What do I need to run it?

64-bit Windows 10 or 11 with the Evergreen WebView2 Runtime. Current Microsoft Edge already includes it, and Microsoft keeps it patched.

Why does Windows warn me when I open it?

The build is not Authenticode-signed yet. SmartScreen may ask you to choose More info, then Run anyway. Each release lists its SHA-256 so you can check the file first.

Does Bowser collect my data?

Bowser has no hosted backend and no first-party telemetry. WebView2's Microsoft Defender SmartScreen checks are on where Windows allows them, and those may send visited addresses to Microsoft.

How does it update?

After Bowser has been open for about a minute it checks the release pinned in the repository, then at most once an hour. A new build is downloaded only when its SHA-256 matches, and installs the next time you start Bowser. You can turn automatic updates off in Settings, Updates.

What is the spoiler shield?

Bowser ships with a GTA VI spoiler firewall, on by default. It hides text, images and video that look like spoilers behind a click-to-reveal cover. Turn it off in Settings, Privacy and security. It is unofficial and not affiliated with Rockstar Games.

How do I change the search engine?

Open Settings, Search engine, and pick Google or DuckDuckGo. The change applies to your next search, with no restart.

Where is my data?

In %LOCALAPPDATA%\Bowser, with one folder per profile. Updating or reinstalling Bowser keeps it.

How do I reset Bowser’s settings?

Open Settings, About Bowser, and choose Reset settings. Your bookmarks, history and passwords stay.

How do I uninstall it?

Run Uninstall-Bowser.ps1 from the repository. It removes the program and its shortcuts and keeps your browser data in %LOCALAPPDATA%\Bowser, which you can delete yourself.

When something goes wrong

Bowser says the WebView2 Runtime is missing
Install the Evergreen WebView2 Runtime from Microsoft, then open Bowser again.
A site looks broken or won’t load something
Open Site information from the padlock and turn blocking off for that site. If that fixes it, tell us the site in an issue so the list can be corrected.
A site can’t use the camera, microphone or location
Permissions start blocked. Allow the one it needs in Site information, from the padlock.
Windows won’t open the download
On the SmartScreen box choose More info, then Run anyway. Compare the file’s SHA-256 with the one on the download page if you want to be sure it’s the real one.
A page shows a spoiler cover you didn’t expect
Click the cover to reveal it, or turn the spoiler shield off in Settings, Privacy and security.
Something else
Open an issue on GitHub with what you did and what you saw.
