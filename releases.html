Your download has started

Windows will probably warn you. That’s expected.

When you open Bowser.exe, a blue box may say “Windows protected your PC”. Bowser isn’t code-signed yet, so Windows doesn’t recognise it. To open it:

  1. Windows protected your PC

    Microsoft Defender SmartScreen prevented an unrecognised app from starting.

    More info

    Don’t run

    1. Click More info.

  2. Windows protected your PC

    App: Bowser.exe
    Publisher: Unknown publisher

    Run anywayDon’t run

    2. Click Run anyway.

Bowser then installs itself and you won’t see this again. Want to check the file first? Compare its SHA-256 with the one on the download page.
